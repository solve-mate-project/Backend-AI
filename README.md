# 알고리즘 문제 관리 시스템

이 프로젝트는 클린 아키텍처와 도메인 주도 설계(DDD) 원칙을 적용하여 개발된 알고리즘 문제 관리 시스템입니다. 다양한 알고리즘 플랫폼(현재는 리트코드)에서 문제를 가져와 Ollama 기반 로컬 LLM을 활용하여 문제 해결을 지원합니다.

## 핵심 기술 스택

- **클린 아키텍처**: 의존성 규칙을 준수하는 계층화된 설계로 유지보수성과 테스트 용이성 확보
- **Ollama**: 로컬에서 실행되는 대규모 언어 모델(LLM)을 활용한 알고리즘 문제 분석 및 해결 지원
- **도메인 주도 설계(DDD)**: 비즈니스 도메인을 중심으로 설계된 엔티티와 리포지토리 패턴 적용
- **Python 비동기 프로그래밍**: async/await를 활용한 효율적인 I/O 처리
